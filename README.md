# شبیه‌ساز جریان ترافیک — نسخهٔ فارسی

این مخزن نسخهٔ فارسی و راست‌به‌چپِ شبیه‌ساز تعاملی ترافیک [MovSim / traffic-simulation-de](https://github.com/movsim/traffic-simulation-de) را در کنار نسخه‌های اصلی انگلیسی و آلمانی نگه می‌دارد. صفحهٔ پیش‌فرض سایت (`index.html`) مستقیماً سناریوی «رمپ ورودی» را به فارسی باز می‌کند.

## اجرا

پروژهٔ اصلی با HTML، CSS و JavaScript معمولی کار می‌کند و به نصب وابستگی نیاز ندارد. برای اجرای محلی، از ریشهٔ مخزن یک سرور ساده اجرا کنید:

```bash
python3 serve.py 8000
```

سپس در مرورگر به نشانی `http://localhost:8000/` بروید (در Codespaces از بخش **Ports**، پورت ۸۰۰۰ را باز کنید). بازکردن مستقیم فایل با `file://` ممکن است بارگذاری راهنماها را به‌دلیل محدودیت امنیتی مرورگر مسدود کند. سرور `serve.py` فایل‌های مخفی مانند `.git` را مسدود می‌کند؛ از سرور سادهٔ `python -m http.server` روی پورتی که عمومی شده استفاده نکنید.

## بخش‌های فارسی

- سناریوهای شبیه‌سازی: مسیر حلقه‌ای، رمپ ورودی و خروجی، عملیات راه‌سازی، سربالایی، مسیر جایگزین، میدان و تقاطع.
- دو بازی آموزشی: کنترل چراغ رمپ و مدیریت مسیر.
- برچسب‌های پارامترها، راهنمای داخل بازی، انتخاب سناریو، پیام‌های بازی و برچسب‌های نمودار.
- چیدمان راست‌به‌چپ، فونت‌های سازگار با فارسی و نام‌های دسترس‌پذیر برای کنترل‌های تصویری.

صفحه‌های انگلیسی و آلمانی اصلی نیز حفظ شده‌اند؛ از گزینه‌های زبان هر صفحه می‌توان به آن‌ها رفت. فایل‌های نام‌دار با پسوند `_fa.html` نسخه‌های فارسی سناریوها هستند.

## استفاده از شبیه‌ساز

- لغزنده‌ها برای تغییر جریان ورودی و پارامترهای رانندگی هستند.
- دکمه‌های بالای صحنه برای مکث/ادامه، بازنشانی و راهنما استفاده می‌شوند.
- در بعضی سناریوها می‌توان علائم ترافیکی را روی مسیر کشید و رها کرد.
- دکمهٔ دانلود داده‌های مسیر خودروها و آشکارسازها را ذخیره می‌کند.

## منبع و مجوز

موتور شبیه‌سازی و دارایی‌های تصویری از پروژهٔ متن‌باز [movsim/traffic-simulation-de](https://github.com/movsim/traffic-simulation-de) گرفته شده‌اند. حق‌نشر و مجوز اصلی در فایل [`LICENSE`](LICENSE) آمده است؛ راهنمای upstream نیز در [`UPSTREAM_README.md`](UPSTREAM_README.md) نگه‌داری می‌شود. تغییرهای این مخزن عمدتاً رابط کاربری فارسی، ترجمهٔ راهنماها و چیدمان RTL هستند؛ منطق مدل ترافیک دست‌نخورده مانده است.
